تخزين منفصل

جداول مخصصة باسم fieldclimate وfieldclimate_stations في Supabase.

عامل مزامنة

خدمة Python خلفية تحفظ القراءات وتحدّث بيانات المحطات.

حالة التنفيذ

قاعدة البيانات: تم تجهيز جدولَي FieldClimate في مشروع Supabase.
البرنامج: تم رفع هيكل عامل Python. لم يُختبر OAuth أو سحب بيانات فعلية بعد.
التشغيل: يحتاج إلى أسرار OAuth وSupabase في بيئة خلفية آمنة.
تكامل METRA: يتطلب استكمال Backend الموحد وربطه بالتطبيق.

الأمان

هذه صفحة ثابتة ولا تتصل مباشرة بقاعدة البيانات. لا تضع كلمات المرور أو مفاتيح API في GitHub Pages أو Flutter. خزّنها في Secrets على خادم التشغيل فقط.
